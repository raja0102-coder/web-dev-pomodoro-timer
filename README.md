# Focus Pomodoro Timer

A productivity web application built with HTML5, CSS3, and vanilla JavaScript implementing countdown intervals, session toggles (Work/Break), and dynamic state management.

## Core Concepts Covered
* **Timing Intervals**: Utilizing `setInterval` and `clearInterval` for precise countdown timing.
* **State Management**: Handling active states, mode switching, and UI updates dynamically.
* **Responsive Styling**: Clean dashboard UI optimized for focus sessions.

## How to View Locally
Open `index.html` in any web browser.
